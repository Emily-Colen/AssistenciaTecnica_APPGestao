# AssistenciaTecnicaAppNovo

Projeto .NET MAUI organizado com a estrutura mínima exigida:

- Models
- Views
- Controllers
- Services
- DAO
- Interfaces

## Como abrir

1. Extraia o ZIP.
2. Abra o arquivo `AssistenciaTecnicaAppNovo.sln` no Visual Studio 2022.
3. Restaure os pacotes NuGet.
4. Compile em `Debug` usando o destino `Windows Machine`.

## Configuração do banco

Ajuste usuário, senha e nome do banco no arquivo:

`Database/DatabaseConfig.cs`

O banco MySQL esperado é `assistencia_tecnica`.
